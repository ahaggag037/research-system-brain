# 0. Mission definition

Design the strongest realistic project named **FixHUA** for a Huawei-class Android phone.

Execute the mission exclusively inside the clean-room repository `ahaggag037/research-system-brain` on `main`. Repository isolation is a hard mission constraint.

The desired real-world outcomes are:
- better responsiveness,
- smoother interaction,
- less stutter/jank/long pauses,
- better multitasking continuity,
- fewer avoidable application reloads/exits,
- better application resume quality,
- stronger sustained stability,
- better predictability under changing workloads,
- and intelligent management rather than a static collection of generic tweaks.

Assume root access can be available when justified.

Root is a capability, not the product definition.

Do not assume the correct product category in advance.

The target should have a credible path to a useful installable/testable first build in **hours of focused engineering where feasible**, while the long-term design may be richer.

There is **no fixed research deadline**. Use diminishing marginal value of new information as the stopping rule.
